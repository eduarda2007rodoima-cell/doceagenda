# DoceAgenda

Agenda digital acadêmica para confeiteiras centralizarem encomendas, agenda e pagamentos.

## Tecnologias
React, Vite, CSS, Lucide React e localStorage.

## Instalação
```bash
npm install
```

## Execução
```bash
npm run dev
```

## Build
```bash
npm run build
```
